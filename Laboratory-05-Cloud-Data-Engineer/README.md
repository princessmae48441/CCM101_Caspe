# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory introduced cloud storage and object storage using MinIO. The activity focused on deploying an object storage server using Docker, accessing the MinIO Web Console, creating a bucket, and uploading a sample file. Through this activity, I gained practical experience in managing cloud storage using a containerized environment.

## Objectives

- Understand the basic concepts of cloud storage.
- Learn the purpose of object storage.
- Deploy a MinIO object storage server using Docker.
- Configure MinIO using environment variables.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a sample file to the bucket.
- Verify the MinIO deployment using Docker commands.
- Document the deployment process.

## Skills Learned

Through this laboratory, I learned how to deploy an object storage server using Docker and configure it using environment variables. I also learned how to map ports to access the MinIO Web Console and how to create a bucket for storing files.

I gained practical experience in using the MinIO Web Console to manage buckets and uploaded files. I also improved my skills in using Docker commands, working with a Linux terminal, troubleshooting deployment issues, and documenting technical procedures using Markdown.
